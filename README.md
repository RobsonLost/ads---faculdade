# 🎓 Análise e Desenvolvimento de Sistemas (ADS)

Bem-vindo ao meu repositório da graduação em **Análise e Desenvolvimento de Sistemas**.

Este espaço foi criado para documentar minha evolução acadêmica ao longo da faculdade, reunindo **anotações, resumos, atividades, projetos e materiais de estudo** desenvolvidos durante o curso.

Além de servir como registro da minha jornada de aprendizado, este repositório também faz parte do meu portfólio profissional, demonstrando minha evolução nas áreas de **Desenvolvimento de Software, Infraestrutura, Análise de Dados e Cibersegurança**.

---

## 🎯 Objetivos

* Organizar os conteúdos estudados durante a graduação;
* Registrar aprendizados e evolução técnica;
* Centralizar projetos acadêmicos e exercícios;
* Criar uma base de conhecimento para futuras consultas;
* Compartilhar minha trajetória de aprendizado em Tecnologia da Informação.
