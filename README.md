# ADS — Registro Acadêmico

Repositório de acompanhamento da graduação em **Análise e Desenvolvimento de Sistemas (ADS)**, na modalidade EAD. Aqui reúno anotações, resumos, exercícios, projetos e materiais de estudo produzidos ao longo do curso, organizados por semestre e disciplina.

Além de funcionar como um diário de estudos, este repositório também serve como registro do meu desenvolvimento técnico nas áreas de Desenvolvimento de Software, Infraestrutura, Análise de Dados e Cibersegurança.

## Objetivos do repositório

- Organizar os conteúdos estudados ao longo da graduação
- Documentar o aprendizado e a evolução técnica disciplina por disciplina
- Centralizar projetos acadêmicos e exercícios práticos
- Servir como base de consulta para revisão futura
- Registrar decisões e dificuldades encontradas durante os estudos, não apenas o resultado final
